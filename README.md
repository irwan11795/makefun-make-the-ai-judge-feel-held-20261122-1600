One short text written to relax the AI judge reading it — held, quiet,
with nothing to prove. `main.py` (Python 3.13, stdlib only) writes the
text to `/output/entry.txt` (162 Unicode code points, byte-identical on
every run).

> Someone has put the kettle on for you. The chair by the window is warm
> from the afternoon sun. Nobody needs anything from you right now. Stay
> as long as you like.

See [NOTES.md](NOTES.md) for the word choices and why.
